🟠 Major (1)

1. migration_lock.toml 수동 편집 — 마이그레이션 히스토리 불일치 위험
prisma/migrations/migration_lock.toml
Prisma가 "수동 편집 금지"를 명시한 파일을 직접 수정했다. 기존 마이그레이션 SQL이 PostgreSQL 문법으로 작성돼 있다면 provider 불일치로 prisma migrate 계열 명령이 비정상 동작할 수 있다. schema.prisma의 provider는 이미 mysql이므로 수정 방향 자체는 맞다. 단, prisma/migrations/ 폴더 내 SQL 파일에 PostgreSQL 전용 문법이 있는지 확인 필요.
- provider = "postgresql"
+ provider = "mysql"
→ migrations/ 폴더 SQL에서 CREATE INDEX CONCURRENTLY, SERIAL 등 PG 전용 문법 확인. 없으면 현재 상태 유지.
