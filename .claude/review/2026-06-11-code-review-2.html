이슈 목록

🔴 Critical

1. techSpecs as string[] — Prisma Json 타입 unsafe 캐스팅 ✓ --fix 적용됨
portfolio/route.ts:22  ·  portfolio/[id]/route.ts:42

Prisma Json 필드는 런타임에서 어떤 JSON 값이든 될 수 있다 (object, number, null 등). TypeScript 컴파일러는 이 캐스팅을 허용하지만, DB에 배열이 아닌 값이 저장되어 있으면 Array.prototype.map 호출 시 런타임 TypeError가 발생한다.

// ❌ Before
tags: p.techSpecs as string[]

// ✅ After
tags: parseTags(p.techSpecs)

function parseTags(raw: unknown): string[] {
  if (!Array.isArray(raw)) return []
  return raw.filter((item): item is string => typeof item === 'string')
}
