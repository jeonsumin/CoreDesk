🟠 Major

Major1. 공개 URL 복사가 window.location.origin 기반 — localhost 문제 재발
PortfolioPublicToggle.tsx:35

관리자가 서버 내부(http://localhost:3000)에서 앱에 접근하면 복사된 URL도 http://localhost:3000/portfolio/...가 된다. API 이미지 URL에서 방금 수정한 것과 동일한 문제다.

Before
const url = `${window.location.origin}/portfolio/${id}`
After — 방법 A: NEXT_PUBLIC_APP_URL 환경변수 추가 (권장)
// .env
NEXT_PUBLIC_APP_URL="https://your-domain.com"

// PortfolioPublicToggle.tsx
const base = process.env.NEXT_PUBLIC_APP_URL ?? window.location.origin
const url = `${base}/portfolio/${id}`
After — 방법 B: 서버 컴포넌트에서 prop으로 전달
// portfolios/[id]/page.tsx (Server Component)
const publicUrl = `${process.env.NEXTAUTH_URL ?? ''}/portfolio/${portfolio.id}`

<PortfolioPublicToggle id={portfolio.id} isPublic={portfolio.isPublic} publicUrl={publicUrl} />
Major2. <img> 태그 직접 사용 — 이미지 최적화 누락
portfolio/[id]/page.tsx:76 portfolio/[id]/page.tsx:101

공개 포트폴리오 페이지는 외부 사용자가 접근하는 퍼블릭 페이지다. eslint-disable 주석으로 Next.js 경고를 억제하고 <img>를 사용해 WebP 변환, 크기 최적화, 지연 로딩이 빠진다. /api/portfolio/images/* 는 내부 라우트이므로 remotePatterns 등록 없이 상대 경로로 next/image 사용 가능하다.

Before
// eslint-disable-next-line @next/next/no-img-element
<img
  src={publicImageUrl(portfolio.thumbnailFile.id)}
  alt={`${portfolio.title} 썸네일`}
  className="h-full w-full object-cover"
/>
After
import Image from 'next/image'

<Image
  src={publicImageUrl(portfolio.thumbnailFile.id)}
  alt={`${portfolio.title} 썸네일`}
  fill
  className="object-cover"
/>

🟡 Minor

Minor3. 두 번의 순차 DB 조회 — 단일 OR 쿼리로 통합 가능
images/[id]/route.ts:18-33

현재 단락 평가 방식이지만 단일 OR 쿼리가 더 직관적이다.

Before
const portfolioByImage = await prisma.portfolio.findFirst({
  where: { isPublic: true, images: { some: { fileId: id } } },
})
const portfolioByThumbnail = portfolioByImage
  ? null
  : await prisma.portfolio.findFirst({
      where: { isPublic: true, thumbnailFileId: id },
    })
After
const portfolio = await prisma.portfolio.findFirst({
  where: {
    isPublic: true,
    OR: [
      { thumbnailFileId: id },
      { images: { some: { fileId: id } } },
    ],
  },
  select: { id: true },
})
if (!portfolio) return new NextResponse('Not Found', { status: 404 })
